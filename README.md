# SNAP-EBT & WIC Benefits Tracker — mobile release

This private repository contains the reviewed source archive, release overlay, and guarded GitHub Actions workflows for the iOS application. The same React Native/WebView interface is intended to support a later Android test-ad build.

## Current product

- Local-first manual tracking for SNAP/PAN, WIC benefits, a shopping budget, grocery baskets, History, and reports.
- CSV, XLSX, PDF, and History-backup exports.
- One non-personalized Google Mobile Ads banner on eligible screens; no banner on Cards & Budgets or in modal, checkout, and export flows.
- No subscription, in-app purchase, rewarded ad, interstitial ad, native ad, account, or publisher-operated cloud database.
- No application-triggered vibration or haptic feedback.

The tracker is independent and is not an official government, EBT, WIC, retailer, payment, or eligibility application.

## Release lanes

- `Validate latest iOS release` is the secret-free compile and integrity gate. It validates TypeScript, the reviewed app and logo digests, an unsigned iPhone archive, and an iOS Simulator build.
- `Upload TestFlight internal build with test ads` is manual, protected, main-only, App Store Connect identity-checked, and permanently internal-TestFlight-only.
- Test builds use Google's official demo app and banner IDs. Production ads require separate verified identifiers and a new build number.

The upload workflow intentionally fails until the CocoaPods lock generated by the validation bootstrap is reviewed and committed as `release-overlay/ios/Podfile.lock`.

No Apple private key, certificate, provisioning profile, live advertising identifier, payment credential, or production secret belongs in this repository.
